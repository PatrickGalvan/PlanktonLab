Guided workflow

Train in Google Colab

1. Set up Google Colab

  • Navigate to: Google Colab
  • Set Runtime to "GPU"
  • Upload this requirements file into the runtime
  • Upload your zipped Training Set into the runtime
  • Run the following commands in a code block
    • 
    # Install requirements
    !pip install -r '/content/requirements_training.txt'
    # unzip trainingsdata
    !unzip /content/[your_trainingset].zip

    2. Configure the training run

  • Open new Code Block and run the following Code:
    • 
    # Global Variables
    from fastai.vision import *
    from fastai.vision.all import *
    import numpy as np
    
    path = '/content/[your_trainingset]'
    num_of_epochs = 10
    data = ImageDataLoaders.from_folder(
        path,
        train="train",
        valid="valid",
        item_tfms=Resize(224),
        num_workers=4,
        batch_tfms=[Normalize.from_stats(*imagenet_stats)])
    learn = vision_learner(
        data,
        models.resnet18,
        metrics=[error_rate, accuracy])
        
        print(
            f"Classes : {data.vocab} \n training_set_size: {len(data.train_ds)} \n validatiion_set_size: {len(data.valid_ds)}"
            )

    3. Train the model

  • Run Code to train your Model
    • 
    # train model
    learn.fit_one_cycle(num_of_epochs)
    learn.save('Zooplankton-v2-resnet18-stage-1')
    # Re-run following lines for further training
    learn.unfreeze()
    lr = learn.lr_find()
    learn.fit_one_cycle(num_of_epochs, lr = lr.suggestion())
    learn.save('Zooplankton-v2-resnet18-stage-2')

    4. Export the model

  • Save Model to runtime and Download it to your filedestination
    • 
    # export Model
    learn.export('/content/[your_models_name].pkl')
